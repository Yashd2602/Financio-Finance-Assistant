# Financio Zorvyn

A finance dashboard built with React + Vite.

## Run locally

1. Install dependencies:

```bash
npm install
```

2. Start development server:

```bash
npm run dev
```

## Deploy to GitHub Pages

1. Push this project to a GitHub repository.
2. Run deploy:

```bash
npm run deploy
```

3. In GitHub, open repository settings:
	- Go to Pages
	- Source: Deploy from a branch
	- Branch: gh-pages
	- Folder: /(root)
4. Save and wait for the site to publish.

After publishing, your app URL will be:

`https://<your-github-username>.github.io/<your-repository-name>/`
